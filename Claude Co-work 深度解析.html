Sam Altman 视角分析

OpenAI CEO | AI 行业领袖

"Anthropic 的 Co-work 产品代表了一个我们都在追逐的方向 —— 将 AI 的能力从对话延伸到行动。这不是简单的 UI 包装，而是在重新定义人机协作的边界。当 Boris 说 '过去两个月 100% 的代码都由 Claude 编写' 时，这印证了我们一直在说的：AI 正在从助手进化为真正的协作者。"

🎯 战略洞察

Co-work 的核心创新在于降低 Agent 使用门槛。Claude Code 对工程师很友好，但 Co-work 让普通人也能驾驭 AI Agent。这是 AI 民主化的关键一步。

⚠️ 竞争警示

他们在安全性设计上投入的资源令人印象深刻 —— 虚拟机隔离、删除保护、prompt injection 防护。这是我们需要加速追赶的领域。

🔮 趋势预判

"并行运行多个 AI 实例"将成为新的工作范式。Boris 同时运行 5-10 个 Claude，这预示着未来的知识工作者都会成为"AI 管理者"。

💡 启发借鉴

Skills 系统 + MCP 连接器的组合是可扩展性的关键。允许用户自定义工作流，而不是强制标准化流程，这是产品设计的智慧。

📌 什么是真正的 Agent？

Boris 指出，"Agentic"这个词已经被滥用到失去意义。真正的 Agent 与普通聊天 AI 的核心区别是：

💬 普通 AI

只能生成文本回复、搜索网页——本质上是"说"

⚡ Agent AI

能使用工具、操作电脑、与真实世界交互——能"做"

🏗️ Co-work 的技术架构

📦
底层引擎：Claude Agent SDK
与 Claude Code 完全相同的核心能力，同一套最强 Agent 能力
🖥️
UI 层：简化的桌面应用
macOS 桌面端（Windows 即将推出），无需终端操作
🔌
扩展能力：MCP + Skills
连接任意工具，自定义特定领域能力

💡 使用心智模型转变

1 操作系统思维：Co-work 直接操作你的文件系统，而不只是生成建议
2 并行处理：不要深入单一任务，而是同时启动多个任务
3 管理者角色：你的工作是"照看"Claude，确保它们不被卡住

🛡️ 多层安全防护体系

Boris 强调 Anthropic 作为"AI 安全实验室"，在 Co-work 上投入了大量安全研究：

安全层级 具体措施 作用
模型层 对齐训练 + 机械可解释性研究 确保模型行为符合用户意图
执行层 虚拟机隔离运行环境 操作不影响主系统
交互层 删除保护确认机制 防止误删关键文件
网络层 Prompt Injection 防护 防止恶意网页操控 Agent
权限层 显式文件夹授权机制 默认无法访问任何文件

🔬 机械可解释性研究

Boris 提到的一个关键点：Anthropic 研究 AI 神经元的方式"就像研究人类大脑一样"——识别结构、以科学方法研究模型的"黑盒"。这是当前 AI 安全领域最前沿的研究方向。

🎯 核心三原则

1️⃣ 使用 Opus 4.5 + Thinking

虽然更大更慢，但需要更少的 token，实际更快更便宜

2️⃣ 维护好 Claude.md

团队共享知识库，每次 Claude 犯错就更新，不重复犯同样的错

3️⃣ 让 Claude 验证输出

用 Chrome 扩展让它看到结果，就像画家不能蒙眼作画

📱 多终端并行工作流

💻
终端：核心开发
多标签页，每个独立 Git checkout，随时跳转
📱
手机：早晨启动
醒来就用 iOS 应用启动 3-5 个任务，稍后检查
🌐
Web：溢出任务
终端标签不够时，在网页版继续开新任务

📝 Plan Mode 的正确打开方式

Boris 最常用但他认为仍被低估的功能：

1️⃣
启动时默认 Plan Mode
让 Claude 先理解目标，生成执行计划
2️⃣
反复迭代直到计划满意
这是你投入时间的地方，不是代码
3️⃣
然后切换到 Auto Accept
Opus 4.5 的执行力：好计划 = 好代码

🔧 GitHub Action 集成技巧

1 运行 /install-github-action 安装 Claude App
2 在 PR 中 @claude 让它修改代码或更新 Claude.md
3 在 Issue 中 @claude 让它自动处理 bug report
4 核心理念：不应该对同一件事评论两次

📈 指数思维 vs 线性思维

Boris 分享了一个关键洞察：

"去年年中，Dario 和我都预测到年底人们不会再手写代码了。当时看起来不可能，但只有相信指数曲线、真正画出那条线的人，才能预见到这一点。我们的肉脑是线性的，而 AI 是指数级的。"
