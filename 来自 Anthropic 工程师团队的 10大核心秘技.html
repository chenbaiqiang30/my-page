1 ⚡ 并行工作：单一最大生产力解锁
▼
核心洞察：同时运行3-5个独立工作区，效率倍增...
核心策略：Git Worktree 多开
同时开启 3-5个 Git Worktree，每个运行独立的 Claude 会话。这是团队公认的 最大生产力突破口。
实战技巧

• 设置 Shell别名：za、zb、zc，一键切换不同工作区

• 建立 专属分析区：只用于读日志、跑BigQuery

• Claude Desktop 已原生支持 Worktree（感谢 @amorriscode）

# 创建并管理多个工作区
git worktree add ../feature-a feature-a
git worktree add ../feature-b feature-b
git worktree add ../analysis main # 专用分析区

# Shell别名配置
alias za="cd ~/projects/worktree-a && code ."
alias zb="cd ~/projects/worktree-b && code ."
alias zc="cd ~/projects/worktree-c && code ."
2 📋 计划模式：一击必杀的秘密
▼
把精力投入计划，让Claude一次性完美实现...
"把精力倾注在计划上，让Claude一次性完美实现。"
双Claude交叉审核法

Claude A 负责编写计划方案

Claude B 以高级工程师视角审核

计划通过后，再启动实现阶段

黄金法则

• 事情一旦跑偏，立即切回计划模式，不要硬撑

• 验证步骤也要进入计划模式，不只是构建阶段

• "Don't keep pushing" —— 感觉不对就重新规划

# 提示词示例
"进入计划模式，详细规划这个功能的实现步骤"
"以Staff Engineer的视角审核这个计划"
"验证阶段也请进入计划模式"
3 📝 CLAUDE.md：让AI自我进化
▼
Claude编写自己的规则，错误率显著下降...
"Claude在编写自己规则这件事上，厉害得有点诡异。"
核心方法论

每次纠正Claude后，结尾加一句：

"更新你的CLAUDE.md，确保不再犯这个错误"

然后 持续迭代优化，直到错误率明显下降

进阶技巧

• 让Claude为每个任务/项目维护 notes目录

• 每次PR后更新笔记

• 在CLAUDE.md中 指向这些笔记

4 🛠️ 技能系统：复用的艺术
▼
一天做两次以上的事，就该做成技能...
核心原则
一天做两次以上的事，立即转化为技能或命令，提交到Git永久复用。
必备命令：/techdebt
每次会话结束时运行，自动 发现并清理重复代码，保持代码库整洁。
多源同步命令
构建一个命令，同步7天内的Slack、GDrive、Asana、GitHub数据，形成完整的上下文。
数据分析Agent
构建分析工程师风格的Agent，自动编写 dbt模型、审核代码、在开发环境测试变更。
5 🐛 自动修Bug：零上下文切换
▼
粘贴Bug线程，说"fix"，搞定...
"粘贴Slack的Bug线程，说一个字'fix'，搞定。"
Slack MCP 集成
开启Slack MCP后，直接把Bug讨论线程粘贴给Claude，无需任何额外说明，零上下文切换。
CI自动修复

直接说："去修复失败的CI测试"

不要微观管理具体怎么做，让Claude自己搞定。

Docker日志诊断
让Claude直接读取 Docker日志 来排查分布式系统问题，它在这方面 出人意料地强。
6 🎓 提示词进阶：挑战Claude
▼
让Claude考验你，成为你的代码审核员...
挑战模式

"Grill me on these changes and don't make a PR until I pass your test"

让Claude 考验你，在你通过测试前不允许提交PR。

优雅重构
当修复不够优雅时，说：

"Knowing everything you know now, scrap this and implement the elegant solution"

详细规格说明
交付任务前，写 详尽的规格说明，减少歧义。你越具体，输出越好。
7 💻 终端环境：工欲善其事
▼
Ghostty终端、tmux管理、语音输入...
推荐终端：Ghostty
团队最爱！支持 同步渲染、24位色彩、完美Unicode。
状态栏配置
用 /statusline 自定义状态栏，实时显示 上下文使用量 和 当前Git分支。
标签页管理

• 用 tmux 或原生标签页

• 颜色编码 + 命名，每个标签对应一个任务/工作区

语音输入神器

macOS按两下 fn键 启用语音输入

说话速度是打字的 3倍，提示词自然更详细！

8 🤖 子代理：算力翻倍
▼
多个AI并行工作，主代理上下文保持清爽...
一键启用
在任何请求后面加 "use subagents"，让Claude调动更多算力处理问题。
上下文管理
把独立任务 外包给子代理，保持主代理的上下文窗口 干净聚焦。
Opus 4.5 智能审批
通过Hook把权限请求 路由到Opus 4.5，让它扫描攻击风险，自动批准安全操作。

10 📚 学习模式：理解力加速器
▼
让Claude解释每个改动背后的"为什么"...
解释模式
在 /config 中启用 "Explanatory" 或 "Learning" 输出风格，让Claude解释每个改动背后的 "为什么"。
可视化HTML演示
让Claude生成 可视化HTML演示文稿 来解释不熟悉的代码——它做幻灯片的能力出人意料地强！
ASCII架构图
让Claude画 ASCII图 来展示新协议和代码库结构，快速建立心智模型。
间隔重复学习
构建 间隔重复技能：你解释理解，Claude追问漏洞，保存结果用于复习。
