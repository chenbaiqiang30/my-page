什么是 Moltbot？

▼

Moltbot（原名 Clawdbot）是一个开源的AI Agent框架，可以将顶级大模型（Claude、GPT等）变成一个真正的数字员工。它不是工具，而是Team Member。

🧠
情景感知能力
跨平台记忆一致，在Discord问的问题，到Telegram它也记得
🔗
多渠道接入
支持Telegram、Discord、WhatsApp、Slack、飞书等主流IM
⚡
完整系统权限
能做人类在电脑上能做的一切：写代码、控制浏览器、管理文件
💓
Heartbeat机制
定时检查任务进度，主动追问，像真正的助理一样

安装部署要点

▼
Step 1: 准备环境

选择部署平台：Mac mini（桌面级体验）或 Linux VPS（低成本，约168元/年）

⚠️ 不要在主力机上部署，项目还不够稳定

Step 2: 一键安装
# 官方一键安装命令 curl -fsSL https://moltbot.dev/install.sh | bash
Step 3: 配置API Provider

支持主流API：Claude（推荐）、Gemini、OpenAI等

Linux无图形界面时，需手动复制OAuth链接到浏览器完成授权

Step 4: 接入IM平台

以Discord为例：创建Bot → 获取Token → 配置权限（管理员/消息/频道）

Step 5: 安全加固

创建专用用户 claude，限制其权限，避免root直接运行

🔒 安全注意事项
  • 如果开放给公域使用，必须做权限隔离，会有人尝试执行 rm -rf
  • 沙箱模式下无法执行Shell，功能受限，建议用独立用户方案
  • 公域Bot需要防prompt injection攻击
  • 不要在主力生产机上部署，项目迭代快，稳定性待验证

飞书接入方案（向阳乔木演示）

▼

向阳乔木分享了如何将Moltbot接入飞书，实现手机随时随地指挥AI：

安装飞书插件

使用开源的飞书配置代码，在Moltbot TUI中直接安装

# 进入Moltbot界面 cloud -a dtui # 然后输入：帮我安装这个飞书插件 [粘贴GitHub地址]
配置飞书开放平台

登录 open.feishu.cn → 创建企业自建机器人 → 获取 App ID 和 App Secret

开通权限

在飞书后台开通IM相关权限：消息收发、对话能力等

配置事件订阅

事件和回调 → 选择长链接模式 → 订阅消息相关事件

✨ 飞书接入的优势

  • ✅ 手机版飞书语音转文字体验极佳，说话自动变文字发送
  • ✅ 可以远程让AI写代码并自动部署到网站
  • ✅ 配合Skill插件，实现个人工作流自动化
