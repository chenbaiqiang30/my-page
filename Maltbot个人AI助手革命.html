🔧
CLI > MCP
Agent天生懂Unix。千个小CLI比复杂的MCP更可扩展。调用--help，加载所需内容，然后执行。
🏠
本地运行 = 绕过红线
Gmail API需要大量资质审批。本地运行？直接指向网页让Agent逆向API，40分钟搞定。
📱
App层将被压缩
健身App、记账App、餐厅推荐App...都将被压缩成API，或者直接被Agent的本地存储替代。
⚡
并行化是关键
Codex可以并行处理，Claude需要更多手把手指导。选择工具要看场景，不是模型排名。
🎭
模型性格很重要
Opus在Discord上表现出的"人性"——知道何时不回复、偶尔抛出好笑的梗——是可量化的产品差异化。
🔐
安全是真实问题
为可信单用户设计的系统被放到公开互联网上，所有threat model都失效了。Prompt injection依然无解。

Peter的AI觉醒之路

从倦怠到重生的完整时间线

▼
13年创业 → 3年休息 → AI黑客重生...
2009-2022
🏢 创业13年：iOS/Apple生态深耕

经营自己的软件公司，专注Apple生态。最终完全倦怠，用他的话说："感觉像有人把我的Mojo吸走了"。

2022-2024
🏖️ 休养期："每4年需要1年休息"

按他的数学：13年连续工作 ÷ 4 ≈ 3年恢复期。期间错过了AI"真的很差"的阶段。

2024年2月
⚡ 关键触发：Claude Code Beta发布

完美的回归时机——AI从"还行"变成"相当不错"。开始失眠、凌晨4点给朋友发消息（朋友也秒回）。

2024年4月
🔥 火花回归 + Cloud Code Anonymous

创建Cloud Code Anonymous聚会（后更名Agents Anonymous）。"积极的成瘾"开始。

2024年5月
💡 首次尝试：个人Agent概念

用GPT-4.1试水，模型不够好。判断"大公司几个月后会做出来"，暂时搁置。

2024年11月
🤔 转折点："我的Agent在哪里？"

大公司依然没做出来。决定自己动手——从"想在WhatsApp上和电脑聊天"开始。

2024年11月（同月）
🚀 马拉喀什顿悟

在摩洛哥旅行时，Agent自主处理语音消息（用ffmpeg转码 → 找到OpenAI Key → curl调用转录）。"这些东西是该死的聪明野兽。"

2025年1月
🌋 病毒式爆发 + 品牌重塑

GitHub史上最陡增长曲线。收到Anthropic友好通知（非律师函），24小时内完成更名至Maltbot。"我们现场搞"meme时刻。
